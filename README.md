## 📌 Overview

This repository includes demo projects and practice code following Section 8 of the course.  
The focus is on implementing **Spring Security** for MVC applications, including:

- Login forms with home page setup
- In-memory user details manager
- Custom login page with error handling and Bootstrap styling
- Role-based URL restrictions
- Role-based content display
- Logout functionality
- JDBC authentication with BCrypt encryption and custom tables
